# 牛头破阵者冲锋 V4：体前低位携斧

替换 V3 冲锋；其他五动画、全部美术、骨架静止结构、网格权重不变。总长 4.2 秒、冲锋窗口 0.60–3.48 秒、6 步态周期、2880 源像素根位移、56 度俯身、skill_hit 3.24 秒全部沿用已批准版本。

## 修复"持斧手压腰"

V3 将斧改为身后拖曳后，用户复审发现持斧手 (400,860) 仍压在裙甲上缘/腰带角上，且手与斧画在最顶层，读感为拳头嵌进腰部。几何核算表明：俯身姿态下双肩前置，双臂均够不到身体后缘之外的净空区，因此身后携带无解。V4 改为体前低位携带：0.18–0.60 秒持斧手在胸腹前缘外侧的净空区完成前下方挥落，冲锋全程手在 (760,950)（距肩约 85 源像素，避免过度折叠），斧刃悬在领前腿旁（骨盆前约 283、下方约 305 源像素，距地约 105）。手、柄、刃全程不进入躯干与裙甲投影，腰带区域完全净空。挥落、携带与收势均在身体前方完成，属正确的近侧遮挡关系。

## 腕部解算

初版体前携带将肘部解向躯干后方，深度折叠下前臂自下前方翘起，与 150 度斧向夹出约 140 度的腕部反折，读感为手腕断裂。现携带窗口（0.18–3.95 秒）改用肘部朝前的解算分支：前臂与斧杆同向，腕部接近平直；窗口两端手臂接近伸直，两侧解算分支在此重合，切换无跳变。3.48 秒后整条手臂按平滑权重在旋转空间混回静息姿态，斧随前臂抬起收势，首帧与待机逐帧衔接一致（项目先例：V2 普攻的按权重收臂）。
