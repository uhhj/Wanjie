# 牛头破阵者生产计划

目标为完整大型双足战斗资产及六个原生动画，不扩展其他系统。冻结来源依次为设计、战斗外观、Rig母图、收藏原画；收藏原画禁止提取战斗像素。主工作目录是独立Git worktree，原仓库中的百夫长未提交工作保持不动。

Rig采用BIPED_LARGE_RIG_V1，按牛头破阵者实际关节、宽胸、重头、蹄足重新定长，不套用罗马盾兵的人体比例。头与双角作为一体的头部美术；独立肩甲、膝甲候选需要审查，双手斧采用主握柄和辅助握柄约束。默认图为单手静持，攻击/技能过渡为双手握持，必须检查距离可达性及手掌遮挡。

普通攻击表现重斧劈落，skill_01表现先压低重心再向前破阵推进和重击，不能只是放大普通攻击。attack_hit与skill_hit分别由AnimationPlayer method track触发。Rig不处理伤害或蓝条增益；只定义外部蓝条满后调用技能的接口约定。

流程：源图SHA冻结→局部遮挡补全候选及未编辑像素保护→RGBA/战斗尺寸门禁→像素优先部件及关节重叠→原生装配和双手接触→六动画→Rig Lab→20/50大型单位实际GPU压力与遮挡审查。正式部件未通过前不得把候选报告写成PASS。

实际尺寸初始为360px/288px，并与256px罗马盾兵并排评估；压力测试使用1920×1080桌面GPU。孤立单元脚底接触、斧柄双手接触、角/斧/披风轮廓必须分别验证。高分辨率1–3px边缘不作为战斗素材的单独阻塞。
