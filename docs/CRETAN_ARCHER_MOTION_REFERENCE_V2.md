# Cretan Archer 动作参考 V2

本次三张图只用于动作顺序、关节联动和节奏。角色身份、服装、武器造型、Alpha 与正式像素仍由已经批准的 Body 和20个正式部件决定；禁止从动作参考提取部件或直接使用其人物帧作为 Sprite 动画。

原始五张冻结参考保持不变。新图按原字节复制至 `art_source/odyssey/cretan_archer/motion_reference/`，独立 `source_manifest.json` 记录路径、SHA256、2172×724画布与 RGB 格式。这里的 RGB 是动作示意图格式，不是生产部件格式问题。

## Walk

观察到的线索包括前脚脚跟先接触、支撑时脚掌放平、后脚跟抬起与后脚离地，以及较稳定的上身和受控弓位。图中没有标注近/远腿身份，也不能直接证明完整的八相生物力学循环。

正式循环由 Rig 重新编排 contact/down/passing/up 的近、远两个半周期；passing 的腿部交错和时间关系属于根据运动逻辑编写的姿态，不能称作参考图逐帧提取。V2维持1.05秒、420源像素位移和双支撑换脚，具体关键时间记录于 `reports/cretan_archer/walk_phase_plan.json`。实际骨骼的世界坐标脚底接触与256/192px视觉审查优先于图像相似程度。

## Attack

参考顺序为待机、取箭、搭箭并举弓、持弓臂伸展、拉弦手到脸颊附近、短暂瞄准、放弦随动、收回。图中箭的位置只解释搭箭和释放，不授予替换正式箭资产的权限。具体时序、手腕/弦/箭连接由原生 Rig 实测；`attack_release` 必须通过 AnimationPlayer method track 恰好发出一次。

## Death

参考顺序为捂胸失衡、上身前折、屈膝下沉、一膝及手支撑、前侧倒下、弓落地、蜷曲倒地并保持。重点是连续失去支撑和最终姿态，不能把整个人物简单旋转平放。弓脱手位移属于明确编写的装备运动；不需要引入布娃娃、物理掉落或新美术。

三项观察与推断分别记录在 `reports/cretan_archer/native/motion_reference_plan.json`。该记录不代表动画通过，最终结论取决于真实 Godot 渲染、事件和接触测试。
