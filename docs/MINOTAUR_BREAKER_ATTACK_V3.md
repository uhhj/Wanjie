# 牛头破阵者攻击 V3：握柄、展臂与收斧

替换V2的普攻，其他五动画及全部美术、骨架静止结构、网格权重保持不变。

主握点从斧头附近沿柄下移约240源像素，双手间距从约150扩大到约220源像素。通过攻击专用斧挂点位置轨道实现；斧头贴图、静止挂点不变，idle和其他动画明确复位。蓄力阶段换握，真正挥砍阶段双手握点固定。

挥出阶段双臂展开，近侧约95%、远侧约89%骨链最大伸长，不拉长骨头。0.98秒斧刃中心位于骨盆前方866源像素，扩大武器有效作用距离；随后向下落斧、躯干前压。总长2.1秒，命中事件仍在1.06秒且只发一次。

修复收势时把展开角直接乘以混合权重的问题。持斧手全程沿明确的握点和斧方向求解，空手通过位置路径释放回落。1.26秒之后斧方向由140度单调回到0度，累计回收140度，没有额外绕圈或反向甩斧。保留正常提斧回到待机所需的角度变化。
