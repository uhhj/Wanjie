# 牛头破阵者冲锋 V3：柄尾握持与更深俯身

替换 V2 的 skill_01；其他五动画、全部美术、骨架静止结构、网格权重不变。总长保持 4.2 秒，冲锋窗口 0.60–3.48 秒、6 个交替步态、2880 源像素根位移、skill_hit 3.24 秒均与 V2 相同。

## 修复斧身穿体

V2 中远手握在斧柄主握点 (430,860)，斧身几乎水平横穿裙甲与腹部轮廓，属于形态错误。V3 改为先把远手沿斧杆滑到柄尾（挂点沿杆上移 455 源像素），再从体侧低弧线后扫：冲锋全程手在身体后方 (400,860)，斧刃拖曳在身后低空（骨盆后方约 583 源像素），斧身、斧刃与远手都不再进入躯干投影。0.35–0.62 秒的后扫路径向下弯曲以避开肩下不可折叠死区，IK 可达问题为零。收势 3.60–4.20 秒滑回主握点，挂点精确复位。

## 更深俯身

躯干前倾由 V2 的 40 度加深到 56 度，头部随之下压，骨盆下沉由 105 加深到 125；牛角更低领前，披风上扬幅度同步加大。步态、位移与命中时机不变。
