# 牛头破阵者攻击 V4：触地重劈与冲击特效

替换 V3 普攻；其他五动画、全部美术、骨架静止结构、网格权重不变。总长 2.3 秒，命中事件移至 1.14 秒触地时刻，仍只发一次。

## 幅度与触地

蓄力举斧高于 V3（0.50–0.80 秒过顶保持），0.98 秒展臂前伸与 V3 相同（近臂 95%、远臂 89% 骨链伸长），随后 0.16 秒内把斧刃下压入地：1.14–1.34 秒斧刃外缘停在地面线（逐帧数值检查偏差 0.09 源像素，咬地 6 源像素），骨盆下沉 150、躯干前压 55 度跟随。1.56 秒后斧方向单调回升出地，累计回收约 120 度，无反向甩斧。

## 触地冲击特效

特效为程序化原生绘制节点 `scripts/rig/minotaur_impact_fx.gd`，无新增美术文件：AnimationPlayer 值轨道驱动 `progress`（0→1，0.40 秒），绘制地面冲击弧、12 团尘土抛物线云与 5 片深色碎屑，位置锚定在斧刃触地点（源坐标约 870,1491）。seek 逐帧采集与实机播放渲染一致；结束自动隐藏，不残留。

## 验证

`reports/minotaur_breaker/attack_v4_test.json` 与 `formal_attack_v4_test.json` 检查双手握点、双臂伸展、斧刃触地误差（≤10 源像素）、特效起止时机、事件计数和挂点复位；生成期 IK 可达问题为零。360/288 实机 64 帧及 32 帧 GIF 在 `reports/minotaur_breaker/actions_v4/`；视觉审查记录 `actions_v4_visual_review.json`。
